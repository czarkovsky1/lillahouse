# Jaracza 21 — makieta strony

Statyczna makieta strony kamienicy Jaracza 21 w Łodzi (HTML/CSS/JS, bez frameworków).

- `index.html` — strona główna
- `mieszkania.html` — podstrona Mieszkania
- `aktualnosci.html` — listing aktualności, `aktualnosci-dzien-otwarty.html` — szablon wpisu (treść przykładowa)
- `kontakt.html` — podstrona Kontakt (dane, osoba do kontaktu, formularz-makieta, mapa)
- `css/style.css`, `js/main.js`, `assets/` — style, skrypty, zdjęcia i wideo

Wdrożenie: Vercel, projekt statyczny, katalog główny repozytorium, bez kroku budowania.
Formularze są makietami (nie wysyłają danych).
